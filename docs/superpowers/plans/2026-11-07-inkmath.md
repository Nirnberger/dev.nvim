# inkmath.nvim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Neovim plugin that renders inline, display, and multi-line LaTeX math in `.tex` and `.md` buffers as real images in Ghostty (incl. inside tmux), with cursor reveal and live preview.

**Architecture:** Treesitter-based detectors produce `MathNode`s; an async render layer (long-lived MathJax node worker, tectonic fallback) produces cell-grid-sized PNGs into a content-addressed cache; a terminal layer transmits them via the kitty graphics protocol (virtual placements) and the view layer places Unicode placeholder cells with extmarks (`conceal` + inline `virt_text` for inline math, `conceal_lines` + `virt_lines` for display/block math).

**Tech Stack:** Lua (Neovim ≥ 0.11, LuaJIT), mini.test, Node ≥ 18 with `mathjax-full@3.2.2`, `@resvg/resvg-js@2.6.2` (dev: `pngjs@7.0.0`), tectonic + ImageMagick + Ghostscript, kitty graphics protocol, tmux passthrough.

**Spec:** `docs/superpowers/specs/2026-11-07-inkmath-design.md`

## Global Constraints

- Neovim ≥ 0.11 (`conceal_lines`); primary target 0.12.5.
- Filetypes v1: `tex`, `markdown` only.
- Never block the main loop on rendering: all renders via `vim.system` callbacks or worker stdio callbacks; results applied with `vim.schedule`.
- Never write to `~/.config/nvim` or the default `nvim` data dirs. All dev/test runs use `NVIM_APPNAME=inkmath-dev`.
- Debounce: 80 ms for buffer updates, 50 ms for live preview.
- Inline math is always exactly 1 row tall. Defaults: `x_height = 0.45`, `baseline = 0.78` (fractions of cell height).
- Image ids are integers in `[1, 2^24 - 1]`; id is encoded as the placeholder highlight's fg `#RRGGBB`.
- Escape sequences go through `vim.api.nvim_ui_send` when it exists, else `io.stdout:write`.
- Inside tmux (`$TMUX` set) every graphics escape is wrapped as `\27Ptmux;` + (payload with every `\27` doubled) + `\27\\`.
- Max resident images default 512; fallback chain per formula `mathjax → tectonic → error marker`.
- Errors never raise into the editing flow: TeX errors become `vim.diagnostic` entries; environment problems produce at most one `vim.notify` per cause.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Escaped and non-math dollars** (`\$5`, `$` inside fenced/inline code in Markdown, `$` in `\verb` or comments): must never be detected as math. → tests in Task 2 and Task 3.
2. **Formula at buffer edges** (display block starting at row 0, or the whole buffer is one formula): virt_lines must still render. → tests in Task 7.
3. **Editing inside a formula while the render of its previous version is still in flight**: a stale result must not replace a newer one. → test in Task 8.
4. **Colorscheme switch / cell size change** (`:colorscheme`, font zoom in Ghostty): images must re-render with the new color/size, not show stale cached ones. → tests in Task 9 (cache key from Task 4).
5. **Worker missing or crashing mid-session** (`node_modules` not built, worker killed): formulas fall back to tectonic or the worker restarts; the plugin keeps working. → tests in Task 5.

### Shared types (defined in Task 2, used everywhere)

```lua
---@class inkmath.MathNode
---@field id string        vim.fn.sha256(kind .. "\0" .. (env or "") .. "\0" .. src):sub(1, 16)
---@field kind "inline"|"display"|"block"
---@field src string       TeX without delimiters; for block = full \begin..\end text
---@field env? string
---@field range {srow:integer, scol:integer, erow:integer, ecol:integer}  -- 0-based, end-exclusive

---@class inkmath.RenderCtx
---@field color string     "#rrggbb"
---@field cell_w integer   px
---@field cell_h integer   px
---@field container_px integer  display width in px = (textwidth > 0 and textwidth or win width) * cell_w
---@field macros table<string, string|table>
---@field preamble? string[]   tex only, lines before \begin{document}

---@class inkmath.Image
---@field key string       cache key
---@field path string      absolute PNG path
---@field cols integer
---@field rows integer
---@field ratio number     natural formula height / cell_h before any inline shrink

---@class inkmath.RenderError
---@field message string
---@field backend "mathjax"|"tectonic"
```

### Task 4: MathJax worker (node) and render cache

**Files:**

**Interfaces:**
- Produces, the worker protocol (newline-delimited JSON on stdin/stdout, one response per request, order not guaranteed):
  - Request `{id, tex, display, macros, color, cell_w, cell_h, container_px, x_height, baseline, scale, out}`, where `out` is the absolute PNG path to write.

- Produces: `cache.key(node, ctx, backend) -> string` = `vim.fn.sha256` of `backend, node.kind, node.src, vim.json.encode(macros with sorted keys), ctx.color, ctx.cell_w, ctx.cell_h, (node.kind ~= "inline" and ctx.container_px or 0), config.scale` joined with `"\0"`; `cache.path(key) -> string` (`stdpath("cache") .. "/inkmath/" .. key .. ".png"`); `cache.get(key) -> inkmath.Image|nil` (reads the sidecar `<key>.json` `{cols, rows, ratio}`, nil unless both files exist); `cache.put(key, cols, rows, ratio) -> inkmath.Image`; `cache.clear()`.

- [ ] **Step 3: Implement `worker/mathjax.mjs`**

- Set up `mathjax-full` with `TeX({packages: AllPackages, tags: "ams"})`, `SVG({fontCache: "none"})` and `liteAdaptor`. Build a new `TeX` input per distinct macros JSON, memoized.
- Read the `width`/`height` attributes (in `ex`) and the depth from `style="vertical-align: -Dex"` of the root `<svg>`.
- `px_per_ex = x_height * cell_h * scale`. Replace `currentColor` with `color`.
- Inline:
  - if `h_px > cell_h`, scale uniformly so the height fits `cell_h`;
  - `cols = ceil(w_px / cell_w)`; canvas = `cols*cell_w × cell_h`;
  - the glyph baseline (`h_px - d_px` from the top) lands at `baseline * cell_h`, clamped so the glyphs stay inside the canvas;
  - left-aligned.
- `ratio = h_px / cell_h` before the shrink, returned for both kinds.
- Display: convert with `{display: true, containerWidth: container_px, em: px_per_ex / 0.442, ex: px_per_ex}`. MathJax then centers the content and right-aligns `\tag`/ams numbers inside `container_px`; if the root width attribute is `100%`, use `container_px`. `rows = ceil(h_px / cell_h)`, `cols = ceil(width / cell_w)`; canvas `cols*cell_w × rows*cell_h`, content vertically centered. The placer adds no extra padding, because `cols` already spans the text width.
- Pad by wrapping in an outer `<svg width height>` with a `<g transform="translate(..) scale(..)">`. Render with `new Resvg(svg, {fitTo: {mode: "original"}, background: "rgba(0,0,0,0)"}).render().asPng()` and write to `out`.
- A TeX error is an `merror` node in the output or an exception; its text goes in `error`. Never exit on a bad request.

### Task 5: Render layer — worker client, tectonic backend, fallback chain

**Files:**
- Create: `lua/inkmath/render/mathjax.lua`, `lua/inkmath/render/tectonic.lua`, `lua/inkmath/render/init.lua`
- Test: `tests/test_render.lua`

**Interfaces:**
- Consumes: the worker protocol and the `cache` API (Task 4); `MathNode`, `RenderCtx`; `config.get()` (Task 1).
- Produces: `require("inkmath.render").render(node, ctx, cb)`, where `cb(img: inkmath.Image|nil, err: inkmath.RenderError|nil)` is called exactly once:
  - on a cache hit (any backend, mathjax key checked first), synchronously before `render` returns;
  - otherwise from `vim.schedule`.
- Produces: `render.available() -> {mathjax: boolean, tectonic: boolean}`; `render.shutdown()`.
- `mathjax.lua`:
  - `start() -> boolean` lazily spawns `vim.system({"node", worker_path}, {stdin = true, stdout = <line buffered handler>})`; returns false if `node` is not executable or `worker/node_modules` is missing;
  - `request(req, cb)`;
  - `pid() -> integer|nil`;
  - if the process exits, pending requests get `cb(nil, "worker exited")`; it restarts on the next request, at most 3 restarts per session, after which `start()` returns false.
- `tectonic.lua`: `batch(items: {node, ctx, key}[], cb_each: fun(i, img|nil, err|nil))`.
  - Writes one document into `vim.fn.tempname()`: the preamble from `ctx.preamble` (or `\documentclass{article}\usepackage{amsmath,amssymb}`) + `\usepackage{xcolor}\usepackage[active,tightpage]{preview}` + `\begin{document}`; each formula is a `\begin{preview}\color[HTML]{RRGGBB}<math>\end{preview}` (inline → `$..$`, display → `\[..\]`, block → the src as is).
  - Run: `tectonic --keep-logs --outdir <tmp> doc.tex`.
  - Read height/depth/width (sp) from the `Preview: Snippet <n> <h> <d> <w>` log lines.
  - DPI = `x_height * cell_h * scale / (4.305 / 72.27)`.
  - Per page: `magick -density <dpi> -background none doc.pdf[<n-1>] <png>`, then pad to the cell grid with `magick <png> -background none -gravity <West for inline | Center for display/block> -extent <W>x<H> <out>`, where display `W = container_px` rounded up to whole cells. Inline gets the same shrink and baseline rules as the worker, using the depth from the log. `ratio = (h + d) in px / cell_h`; store it with `cache.put(key, cols, rows, ratio)`.
  - A failed compile → every item gets `cb_each(i, nil, {message = <first log line starting with "! ">, backend = "tectonic"})`.
- Fallback: mathjax error or unavailable → tectonic, if `config.fallback` and tectonic is available → otherwise the error. `config.backend == "tectonic"` skips mathjax. Concurrent requests with the same key share one in-flight entry.

- `"fallback to tectonic on mathjax error"`: src `\mycustom{x}`, `ctx.macros = {}`, `ctx.preamble = {"\\documentclass{article}", "\\newcommand{\\mycustom}[1]{#1}"}` → img returned, and `img.key == cache.key(node, ctx, "tectonic")`.
